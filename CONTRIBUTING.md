# Contributing to mongo-rs

Thanks for considering contributing! This project is maintained by one developer, so community help is valuable.

## Quick start

1. Fork and clone the repo
2. Make your changes
3. Run checks: `shellcheck entrypoint.sh` and `./test.sh`
4. Open a PR

## What to contribute

**Good first contributions:**
- Documentation improvements
- Bug fixes with clear reproduction steps
- Performance optimizations

**Feature ideas:** Open an issue first to discuss. This saves time if the feature doesn't align with the project's direction.

## Code style

- Follow existing formatting
- Write clear, explicit names over abbreviations
- Keep PRs focused on a single concern

## After your PR

PRs are usually reviewed within a few days. If you don't hear back within a week, feel free to ping.
